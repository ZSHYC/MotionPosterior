# MotionPosterior 模型升级方案

本文以 **MotionPosterior** 作为项目公开名称，记录面向高速小目标的时空建模、运动
后验估计和三帧/五帧输入输出契约。当前数据集仍是网球场景，但架构设计不绑定
`rally` 或具体体育项目。`TrackNetV2`、`TrackNetV5`、`TrackNetMotion` 是保留的历史
兼容名称，旧脚本和权重不需要迁移。

## 1. 现状审计

当前公开的 V2/V5 路径把三帧假设写在多处：预处理 CSV 的
`path_prev/path/path_next`、V5 的 `MDD`、`R_STRHead.time_embed`、推理读取循环和
验证可视化。V5 的运动提示是相邻灰度差分的亮/暗四通道，再用门控和 token
上下文参与预测。这个路径继续保留，避免已有三帧权重失效。

新增 `MotionPosteriorNet` 是公开升级路径，`TrackNetMotion` 作为兼容别名保留：

```text
T 帧 RGB (T=3 或 5)
        │
        ├─ 共享 ConvNeXt V2 风格帧编码器
        │       ├─ full / half 特征：保留小球细节
        │       └─ half / quarter / eighth 特征：全局配准 + 局部相关 + offset gate
        │
        └─ 逐帧 U-Net 式融合 → T 张全分辨率热力图
```

## 2. 已实现的升级

### 2.1 五帧训练与推理

`tools/preprocess_data_gauss.py --num-frames 5` 生成中心对称窗口
`prev2, prev, current, next, next2`，并写出
`labels_context5_train.csv` / `labels_context5_val.csv`。`TennisDataset` 显式按
这个顺序整理路径、坐标、可见性和 GT，避免依赖 CSV 或字典的字母序。

训练配置为 `configs/tracknetmotion_convnext_5frames.py`；公开推理使用
`--arch motion_posterior5`。`motion_posterior3` 是同一模型的三帧入口，旧
`motion3`/`motion5` 以及 `v2`/`v5` 入口保持不变。
推理提供三种窗口语义：`chunk` 保留旧的非重叠块行为，`center` 使用真正的中心
滑动窗口，`causal` 使用只看过去帧的在线窗口。默认使用 `chunk`，保证五帧模型
每个窗口输出五张热图；可用 `--window-mode center` 或 `--window-mode causal` 做
单中心帧评估。边界只做帧复制，CSV 仍只写实际解码到的帧。

五帧中心窗口适合离线推理。严格在线因果场景应另设 `[t-4, ..., t]` 的数据导出
策略，不能把未来帧混入在线评估。

### 2.2 ConvNeXt V2 风格骨干

`MotionConvNeXtBackbone` 使用 7×7 depthwise convolution、LayerNorm、GELU、
pointwise expansion 和 GRN（Global Response Normalization）残差块。输出
`full/half/quarter/eighth` 四个尺度；解码器在每个尺度对每一帧共享参数。
这比原来的顺序 VGG 式卷积更适合扩大感受野，同时保留 dense heatmap 所需的
高分辨率分支。

### 2.3 特征级运动表示

在 1/2、1/4、1/8 尺度分别使用半径 1/2/4 的局部跨帧相关。每个邻帧先经过有界
全局平移估计并用 `grid_sample` 做可微补偿，再在补偿特征上计算 3×3 空间相关体；
相关聚合后由密集 2D offset 做一次 deformable refinement。越界邻居用显式 mask
排除，避免循环索引把首尾帧错误地当作邻居。`|feature - aligned|` 形成 motion
residual，经过深度卷积和通道门控后调制对齐特征。整个模块只依赖 PyTorch，可直接
反向传播，不依赖预计算光流。

这个设计把运动从 V5 的单纯像素亮暗差分提升到 feature-level correspondence，
但不引入额外光流网络或第三方依赖。它对应 TEA 的 feature temporal difference
思想和 PSLA 的局部、无需光流的跨帧对应方式。

## 3. 为什么适合高速小目标

高速小球的主要风险是运动模糊、跨帧位移大、目标在深层下采样后只剩几个像素。
因此第一版升级优先做三件事：

1. 让五帧提供更长的短期上下文；
2. 在 1/4、1/8 尺度做局部对应，而不是对全图 token 做昂贵的全局注意力；
3. 保留 full/half 分支并通过跳连恢复到原分辨率，避免只依赖 1/8 特征。

当前全局补偿是特征级的可学习平移，能吸收小幅相机抖动；对于大幅透视变化仍应
单独评估 homography/ECC。几何输出还包含中心 offset、visibility 和 uncertainty，
loss 同时约束速度与加速度，使热图峰值之外的轨迹几何也参与训练。
丰富输出模式还返回 `velocity` 与 `acceleration`，便于后续轨迹滤波器或因子图直接使用。

### 2.4 训练与评估契约

预处理不再把高斯斑点二值化，保留 0..255 的软标签；训练/验证按 clip 分组切分，
避免相邻窗口泄漏。`TrackNetV2Loss` 统一使用 logits 内部的稳定 BCE，并兼容旧模型
概率输出。Runner 保存模型、优化器、调度器、epoch、迭代数和最佳指标，可通过配置的
`resume_from` 继续训练；指标额外报告可见球的平均和 P90 像素误差。
分组留出至少需要两个 clip；若只有一个 clip，预处理会直接报错，避免产生空验证集。

## 4. 外部文献依据

以下链接均为论文原文或 CVF/arXiv 页面：

* [TrackNet (arXiv 1907.03698)](https://arxiv.org/abs/1907.03698)：连续帧数是模型参数，热力图用于网球定位，为 T 帧输入/输出提供任务依据。
* [TrackNetV4 (arXiv 2409.14543)](https://arxiv.org/abs/2409.14543)：运动 prompt 与当前 V5 路径最接近，但仍以帧差为主。
* [LSTFE-Net, CVPR 2023](https://openaccess.thecvf.com/content/CVPR2023/html/Xiao_LSTFE-NetLong_Short-Term_Feature_Enhancement_Network_for_Video_Small_Object_Detection_CVPR_2023_paper.html)：短期特征对齐、长短期聚合，直接针对视频小目标。
* [TEA, CVPR 2020](https://openaccess.thecvf.com/content_CVPR_2020/html/Li_TEA_Temporal_Excitation_and_Aggregation_for_Action_Recognition_CVPR_2020_paper.html)：用 feature-level temporal difference 激发运动敏感通道。
* [PSLA, ICCV 2019](https://openaccess.thecvf.com/content_ICCV_2019/html/Guo_Progressive_Sparse_Local_Attention_for_Video_Object_Detection_ICCV_2019_paper.html)：局部稀疏跨帧对应，不依赖额外光流模型。
* [ConvNeXt V2, CVPR 2023](https://openaccess.thecvf.com/content/CVPR2023/html/Woo_ConvNeXt_V2_Co-Designing_and_Scaling_ConvNets_With_Masked_Autoencoders_CVPR_2023_paper.html)：GRN 和现代分层卷积骨干的依据。
* [QueryDet, CVPR 2022](https://openaccess.thecvf.com/content/CVPR2022/html/Yang_QueryDet_Cascaded_Sparse_Query_for_Accelerating_High-Resolution_Small_Object_Detection_CVPR_2022_paper.html)：高分辨率小目标分支可采用粗定位后局部精修。
* [TAPIR, ICCV 2023](https://openaccess.thecvf.com/content/ICCV2023/html/Doersch_TAPIR_Tracking_Any_Point_with_Per-Frame_Initialization_and_Temporal_Refinement_ICCV_2023_paper.html)：逐帧初始化、局部时空精修和不确定度预测的参考。
* [SMOFlow, CVPRW 2024](https://openaccess.thecvf.com/content/CVPR2024W/EarthVision/html/Khairi_Efficient_Local_Correlation_Volume_for_Unsupervised_Optical_Flow_Estimation_on_Small_Moving_Objects_in_Large_Satellite_Images_CVPRW_2024_paper.html)：针对大背景中的小运动目标设计高效局部相关体，支持本实现的局部搜索取舍。
* [SET, CVPR 2025](https://openaccess.thecvf.com/content/CVPR2025/papers/Sun_SET_Spectral_Enhancement_for_Tiny_Object_Detection_CVPR_2025_paper.pdf)：强调 tiny-object 高频细节，支持保留半/四分之一分辨率分支。
* [UGS, ICCV 2025](https://openaccess.thecvf.com/content/ICCV2025/html/Sun_Uncertainty-Aware_Gradient_Stabilization_for_Small_Object_Detection_ICCV2025_paper.html)：不确定度感知的小目标训练稳定化方向；本实现先采用轻量 heteroscedastic auxiliary loss。
* [VideoMamba, ECCV 2024](https://arxiv.org/abs/2403.06977)：线性复杂度长时序建模的后续方向；对当前五帧短窗口不作为第一版主干。

## 5. 后续迭代顺序

仍可继续做的方向（本次已经覆盖运动对齐、几何辅助头和在线窗口）：

1. **P2 局部精修头**：先用当前热图得到候选，再只在候选邻域计算更高分辨率残差，避免全图高成本分支。
2. **显式全局相机模型**：数据若出现大幅摇摄，再比较 homography/ECC 或几何相机 token。
3. **部署型骨干对比**：若设备延迟是硬约束，再评估 RepViT；若需要更长序列，再评估 VideoMamba temporal neck。

每一步都应以三帧旧模型为基线，至少比较可见球召回、误检率、遮挡恢复和端到端
延迟；不能只看单一 F1。

## 6. 本轮已落地的闭环修复

本轮代码已经把上述升级中最容易出现“训练有效、部署无效”的部分接通：

1. **Motion 可训练初始化**：`motion_scale` 不再从严格零开始；offset refinement
   的最后一层保持近零输出但保留前层梯度。pair-level motion state 根据速度代理和
   不确定性将局部搜索强度连续调节到 `1.0x~2.5x`，同时保持 T=3/T=5 接口。
2. **后验解码统一**：`core/postprocess.py` 现在统一解码 heatmap、normalized
   offset 和 visibility。低可见性样本主动 abstain；旧的 tensor 输出仍走轮廓
   fallback。`track.py` 和 `core/detector.py` 的 Motion 配置显式开启 `return_aux`。
3. **真实标签进入几何监督**：`TennisDataset` 和 `Finalize` 输出稳定的
   `[T,2] float32` 坐标与 `[T] float32` visibility。`Resize` 同步缩放坐标，避免
   loss 继续从量化高斯图反推中心。
4. **可见性门控的鲁棒轨迹损失**：位置、方差、速度、加速度损失只在可见帧或有效
   相邻帧上计算，并支持 `dt/fps`。缺少原始 metadata 时仍回退到高斯质量中心，保证
   旧 CSV 能加载。
5. **训练可复现性**：DataLoader 使用显式 generator 和 worker seed；配置可以打开
   deterministic 模式；checkpoint 保存 Python/NumPy/PyTorch/CUDA RNG 与配置快照，
   并在 scheduler.step() 后保存，恢复时学习率阶段一致。

这些改动仍然不等价于“已经在真实数据上提升精度”。正式实验必须分别报告 3-frame
center、5-frame center、5-frame causal 和 chunk；同时报告 PCK/EPE、miss rate、
visibility recall、P50/P90/P95 和延迟。当前测试覆盖 Motion 梯度、三/五帧形状、
后验解码、标签坐标契约与 loss 屏蔽，但没有替代真实训练和视频基准。
